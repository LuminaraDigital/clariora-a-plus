# CompTIA A+ Deep Dive - Complete Study Guide Index

> Built from a full read of all 22 module decks (A220-1201 M01-M10, A220-1202 M11-M22), all 34 labs, the video library, and the existing `CompTIA_A_Plus_Mastery` files. This folder goes several layers deeper than the 00-09 files one level up. Use those as the quick-recall layer and these as the actual learning layer.

## How the two exams split

| Exam | Code | Files in this folder | Domains (weight) |
|---|---|---|---|
| **Core 1** | 220-1201 | 02-16 | Mobile Devices 15% · Networking 20% · Hardware 25% · Virtualization & Cloud 11% · HW/Network Troubleshooting 29% |
| **Core 2** | 220-1202 | 17-32 | Operating Systems 31% · Security 25% · Software Troubleshooting 22% · Operational Procedures 22% |

Both: max 90 questions, 90 minutes, includes performance-based questions (PBQs). Passing: Core 1 = 675/900, Core 2 = 700/900.

## How to use this folder

1. **Day 0:** watch all 22 videos at 1.5× (≈90 min). Don't take notes.
2. **Per topic:** read the DEEP_DIVE file → close it → answer the "Self-Test" questions at the bottom of each file out loud → reopen and check.
3. **Daily:** 15 minutes on [34_Master_Recall_Tables](34_Master_Recall_Tables.md). Ports every single day.
4. **Weekends:** labs on a throwaway VM (file 33).
5. **Before each exam:** [35_Practice_Questions](35_Practice_Questions.md), then the one-level-up `09_CHEAT_SHEET`.

Sit Core 1 first. Do not interleave.
