## Scenario / PBQ-style drills

**S1.** A user can reach `192.168.1.20` (file server) by IP but not `\\fileserver`. Which single component is faulty and which command proves it?
→ DNS. `nslookup fileserver` fails / `ping fileserver` fails while `ping 192.168.1.20` works. Fix DNS server setting or `ipconfig /flushdns`.

**S2.** Order these: Test the theory · Document · Identify the problem · Verify functionality · Establish theory · Implement plan.
→ Identify → Establish theory → Test → Implement plan → Verify → Document.

**S3.** Match: (1) 3 drives, 1 parity (2) 2 drives, mirror (3) 4 drives, stripe of mirrors (4) 4 drives, 2 parity → RAID 5 / RAID 1 / RAID 10 / RAID 6.

**S4.** Drag ports: SSH, RDP, HTTPS, DNS, SMTP, IMAP → 22, 3389, 443, 53, 25, 143.

**S5.** SOHO router PBQ: change admin password; SSID "Office-5G"; WPA3-Personal; passphrase 16+ chars; channel auto/36; disable WPS & UPnP; firmware update; DHCP reservation for printer; port-forward 443 → 192.168.1.50.

**S6.** Malware on a workstation - order: verify → quarantine → disable System Restore → update AV → scan/remove in Safe Mode → schedule scans → re-enable System Restore, create point → educate.

**S7.** A laptop battery is bulging under the trackpad. Do you (a) keep using until end of shift, (b) discharge fully, (c) power off, remove, place in safe container, dispose per SDS/regulations? → (c).

**S8.** `diskpart` sequence to create a 500 MB NTFS volume W: from free space → `list disk` · `select disk 0` · `list volume` · `select volume 3` · `shrink desired=500` · `create partition primary` · `format fs=ntfs quick label=new` · `assign letter=w`.

**S9.** Share permissions Everyone=Change; NTFS Sales=Read. Sales user over the network can: → Read only (most restrictive). Locally: Read (NTFS only).

**S10.** Full backup Sunday, differentials Mon-Sat. Failure on Thursday: restore how many jobs? → 2 (Sunday full + Wednesday differential). If incrementals instead: 4 (full + Mon, Tue, Wed).
