3. Telegram Mini App specifics

When you open Clariora as a Telegram Mini App, Telegram provides certain data to third-party Mini Apps under the Telegram Mini Apps Terms. According to Telegram, that typically includes your IP address as seen by the Mini App host, and may include your Telegram user id, public name, username, profile picture, client language tag, Telegram Premium status, and theme colour parameters.

Clariora uses that platform data as follows:

  • initData verification. We cryptographically verify Telegram WebApp initData on our Cloudflare Worker before trusting a Telegram identity for entitlements, AI quotas, or payments.
  • Profile fields we store server-side when you use paid / AI / sync features. Telegram user id, username, first name, and last name may be stored in our Cloudflare D1 database to associate entitlements, Stars/TON purchases, AI usage counters, and optional learner sync blobs.
  • CloudStorage. Where supported, we may write study-related keys to Telegram CloudStorage so progress can persist inside Telegram. That storage is provided by Telegram on your account/device context; we do not treat it as a separate marketing database.
  • We do not request your phone number as a condition of using the Mini App core simulator.
  • We do not use Telegram contacts, location, accelerometer, or microphone APIs for Clariora's core study features.

Clariora is a third-party service independent of Telegram. Telegram is not responsible for how we handle data once it is shared with us. Registering this policy URL in @BotFather makes it available from the Mini App Settings privacy button.

5. On-device and Telegram CloudStorage data

Clariora is local-first. Core simulator state is stored in browser localStorage (or equivalent desktop storage) on the device you use. Clearing site data, uninstalling, or switching devices without an export will lose that local progress.

You can export / import a learner backup or sync file from the app when that feature is available. Those files are under your control; if you share them, anyone with the file can read the study data inside.

Inside Telegram, we may also use Telegram CloudStorage for selected keys so progress survives Mini App reloads. Telegram's handling of CloudStorage is governed by Telegram's own terms and privacy policy.

6. Server-side processing (Cloudflare)

Our public web app and API are hosted on Cloudflare (Workers, static assets, and D1 database). When your client calls our API (for example /api/v1/coach, Stars invoice creation, TON confirmation, optional learner sync, Telegram webhook), Cloudflare and our Worker process the request, including standard network metadata such as IP address.

Database tables may include Telegram user records, Stars/TON transaction records, AI usage counters/logs, and optional learner sync blobs keyed to a user id. We use this data to provide the feature you requested, prevent abuse, and keep purchase state consistent.

7. Ghost Coach AI

Ghost Coach is optional. Offline fallbacks can show local explanations without calling a model host. When you use online coaching:

  • Your client sends coaching context (question content, your selection, explanations/distractor notes) plus Telegram initData to our Cloudflare Worker.
  • We verify identity, check free/pro entitlements, then route the prompt to the selected model provider (for example Groq on the free tier; NVIDIA NIM, private Ollama, or OpenRouter on pro tiers, subject to configuration).
  • Those providers process the prompt to return a coaching reply. Do not put secrets, passwords, employer confidential data, or unrelated personal data into coaching prompts.
  • We may log provider name, model, latency, Telegram id, and tier for quota and reliability. We do not use Ghost Coach content to train a public advertising profile about you.

Model hosts are independent controllers/processors for the prompts they receive. Their retention and training policies are outside Clariora's control; review their documentation if that matters to you before using online coaching.

8. Payments (Telegram Stars and TON)

Telegram Stars (XTR)

In-app digital unlocks inside Telegram are fulfilled through Telegram Stars. Telegram and its payment partners process the Stars transaction. We receive payment confirmation metadata (for example product id, Stars amount, Telegram user id, payment charge id / invoice payload) so we can unlock features. We do not receive or store your card number.

TON

If you pay with TON, public blockchain data (transaction hash, amount, wallet address you used) is inherently public on the TON network. We store references needed to confirm payment and grant entitlements. Blockchain records cannot be deleted by us.

Refunds and chargebacks for Stars follow Telegram's rules and tools. Contact us at the email below if you need help matching a purchase to your entitlement.

9. Optional accounts and cloud sync

You can use Clariora without creating an account. Optional sign-in (for example Firebase Authentication with email/password or Google, or Telegram Login) is available so you can sync learning state if you choose.

  • Firebase (Google). If you sign in, Google Firebase Auth (and Firestore when sync is active) processes your account credentials and the learner documents you sync. The shipped Firebase web config includes a Google Analytics measurementId for the Firebase project; Clariora does not currently initialize the Firebase Analytics SDK in the app shell. In-app "analytics" screens compute scores locally from your history and are not a third-party ad network.
  • Supabase sync config. A separate Supabase cloud-sync path exists in code but is disabled by default unless we explicitly enable it with a project URL. If enabled in a future build, synced snapshots would be stored under your signed-in user with row-level security.
  • Manual file sync. Saving or loading a sync file keeps data under your control on disk or cloud folders you choose.

10. Telemetry and product analytics

Clariora can record anonymous product-usage events in a local buffer (random install id, session timing, feature events). By design it excludes names, emails, question text, answer text, and free-form input.

Upload is off by default. Nothing is sent to a remote telemetry endpoint unless (1) we configure an HTTPS endpoint and enable upload in product configuration, and (2) you explicitly consent via the in-app "Share anonymous usage data" control. You can withdraw consent in the same place. Until both conditions are true, telemetry stays on device.

13. Retention

  • On-device data: until you clear it, uninstall, or overwrite it.
  • Telegram CloudStorage keys: until you clear them / Telegram removes them / you stop using the Mini App in a way that drops that storage.
  • Server entitlement and purchase records: kept while needed to provide access, prevent fraud, and meet accounting or dispute needs, then deleted or irreversibly aggregated when no longer required.
  • AI usage logs: kept for quota enforcement and abuse detection for a limited operational period.
  • Support emails: kept as long as needed to resolve your request and for reasonable follow-up.
  • Public blockchain data: permanent by design; we cannot erase TON ledger history.
